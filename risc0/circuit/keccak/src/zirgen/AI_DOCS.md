## Overview

This directory contains the Zirgen-generated circuit implementation for the Keccak cryptographic hash function within the RISC Zero ecosystem. Zirgen is a domain-specific language and compiler for generating zero-knowledge proof circuits, particularly optimized for the RISC Zero proving system.

## Purpose

The Keccak circuit enables efficient zero-knowledge proofs of Keccak hash computations. This is essential for:
- Verifying blockchain state transitions (Ethereum uses Keccak-256)
- Creating privacy-preserving applications that need to prove knowledge of preimages
